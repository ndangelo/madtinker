The following tutorial will teach you how to edit text in Adobe Illustrator using various techniques.


## 1. How to Edit Text in Illustrator


Using the **Selection Tool (V)**, simply **double-click** on the text to edit it.


![how to edit text in Illustrator using the Selection Tool](https://nuggetofjoy.com/wp-content/uploads/EditText1-1.gif)


Using the **Type Tool (T)**, click on the text, and then you can edit it.


![how to edit text in Illustrator using the Type Tool](https://nuggetofjoy.com/wp-content/uploads/EditText2.gif)


If you can't edit text in Illustrator, have a look at the **Layers** panel (**Window > Layers**) and make sure that it's not locked.


If you click your text and you can see an outline around the characters, it means that your text is turned into outlines (vector paths), making your text uneditable.


![when you can't edit text in Illustrator](https://nuggetofjoy.com/wp-content/uploads/EditText2B.jpg)


## 2. How to Further Edit Text in Illustrator


### Step 1


Select some text and use any of the options on the **Type** panel (**Window > Type**) to further edit text in Illustrator.


The **Character** panel (**Window > Type > Character**) is the main panel that you should master. Check out this tutorial to learn all that you need to know about the **Character** panel: [A Beginner's Guide to the Character Panel in Illustrator](https://design.tutsplus.com/tutorials/a-beginners-guide-to-the-character-panel-in-illustrator--cms-42092).


![edit text in Illustrator using Type panels](https://nuggetofjoy.com/wp-content/uploads/EditText3.jpg)


### Step 2


As you would with any other vector shape, you can easily color and style text using basic fill and stroke settings. You can easily set these attributes using the **Toolbar**, the **Control** panel, or the **Properties** panel.


![edit text colors in Illustrator](https://nuggetofjoy.com/wp-content/uploads/EditText4.jpg)

### Step 3


Finally, you can further edit text in Illustrator using the Appearance panel (Window > Appearance). A bunch of well-placed fills, strokes, and effects can turn any text into a work of art.


![edit text in Illustrator using the Appearance panel](https://nuggetofjoy.com/wp-content/uploads/EditText5.jpg)


And the neat thing about these techniques is that your text remains fully editable.


![fully editable text with the Appearance panel](https://nuggetofjoy.com/wp-content/uploads/EditText6.gif)
