<header class="ag-hero"><div class="ag-eyebrow">AMDE 355 · Advanced Web Design</div><h2>CSS Grid: Design Better Layouts</h2><p>Learn to organize webpage content into flexible rows and columns. Build a responsive project gallery using Sublime Text, CSS Grid, and your own design decisions.</p><div class="ag-chips"><span class="ag-chip">CSS Grid</span><span class="ag-chip">Sublime Text</span><span class="ag-chip">Responsive design</span><span class="ag-chip">In-class lab</span></div></header>
<section class="ag-section"><h2>01 / Learning objectives</h2><div class="ag-grid"><div class="ag-card"><div class="ag-number">1</div><h3>Understand the grid</h3><p>Identify grid containers, grid items, rows, and columns.</p></div><div class="ag-card"><div class="ag-number">2</div><h3>Control layout</h3><p>Use column definitions, fractions, gaps, and spanning.</p></div><div class="ag-card"><div class="ag-number">3</div><h3>Design responsively</h3><p>Create layouts that adapt to different viewport sizes.</p></div><div class="ag-card"><div class="ag-number">4</div><h3>Build a real page</h3><p>Write HTML and CSS in Sublime Text and test in a browser.</p></div></div><div class="ag-callout"><strong>Big idea:</strong> CSS Grid is a two-dimensional layout system. It helps you organize content across both rows and columns.</div></section>
<section class="ag-section"><h2>02 / Your first grid</h2><p>Start with a container and six items. The container defines the layout; the items are the elements placed inside it.</p><div class="ag-code"><code>&lt;div class="grid-container"&gt;
  &lt;div class="grid-item"&gt;One&lt;/div&gt;
  &lt;div class="grid-item"&gt;Two&lt;/div&gt;
  &lt;div class="grid-item"&gt;Three&lt;/div&gt;
  &lt;div class="grid-item"&gt;Four&lt;/div&gt;
  &lt;div class="grid-item"&gt;Five&lt;/div&gt;
  &lt;div class="grid-item"&gt;Six&lt;/div&gt;
&lt;/div&gt;</code></div><div class="ag-code"><code>.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

.grid-item {
  padding: 30px;
  background: #e5edff;
  border: 1px solid #b7c9f5;
}</code></div><div class="ag-demo-grid"><span>One</span><span>Two</span><span>Three</span><span>Four</span><span>Five</span><span>Six</span></div><div class="ag-grid"><div class="ag-card"><h3>display: grid</h3><p>Turns the element into a grid container.</p></div><div class="ag-card"><h3>repeat(3, 1fr)</h3><p>Creates three equal-width columns.</p></div><div class="ag-card"><h3>gap: 16px</h3><p>Creates consistent space between grid items.</p></div></div></section>
<section class="ag-section"><h2>03 / Columns and the fr unit</h2><p>The <code class="ag-inline">grid-template-columns</code> property defines the columns. The <code class="ag-inline">fr</code> unit distributes available space in fractions.</p><div class="ag-grid"><div class="ag-card"><h3>Three equal columns</h3><div class="ag-code"><code>grid-template-columns: 1fr 1fr 1fr;</code></div><div class="ag-demo-grid"><span>1</span><span>1</span><span>1</span></div></div><div class="ag-card"><h3>Two equal columns</h3><div class="ag-code"><code>grid-template-columns: repeat(2, 1fr);</code></div><div class="ag-demo-grid" style="grid-template-columns:repeat(2,1fr)"><span>1</span><span>1</span></div></div><div class="ag-card"><h3>Unequal columns</h3><div class="ag-code"><code>grid-template-columns: 2fr 1fr;</code></div><div class="ag-demo-grid" style="grid-template-columns:2fr 1fr"><span>2fr</span><span>1fr</span></div></div></div><div class="ag-callout"><strong>Tip:</strong> <code class="ag-inline">repeat(3, 1fr)</code> is a shorter way to write three equal columns. Use <code class="ag-inline">minmax(0, 1fr)</code> when you need flexible tracks that can shrink without overflowing.</div></section>
<section class="ag-section"><h2>04 / Rows and spacing</h2><div class="ag-grid"><div class="ag-card"><h3>Define rows</h3><div class="ag-code"><code>grid-template-rows: 150px 200px;</code></div><p>This defines two explicit rows. Additional content may create implicit rows.</p></div><div class="ag-card"><h3>Set the gap</h3><div class="ag-code"><code>gap: 20px;</code></div><p>Sets both row and column gaps to 20 pixels.</p></div><div class="ag-card"><h3>Different spacing</h3><div class="ag-code"><code>row-gap: 24px;
column-gap: 16px;</code></div><p>Use separate values when vertical and horizontal spacing need to differ.</p></div></div><p class="ag-muted">For card layouts, let content determine row height when possible. Fixed row heights can cause text or images to overflow.</p></section>
<section class="ag-section"><h2>05 / Make an item span columns</h2><p>A featured project can occupy two columns while the other cards occupy one.</p><div class="ag-code"><code>.featured {
  grid-column: span 2;
}</code></div><div class="ag-demo-grid"><span class="ag-wide">Featured project</span><span>Project 2</span><span>Project 3</span><span>Project 4</span></div><p>To span two rows instead, use <code class="ag-inline">grid-row: span 2;</code>. Use spanning to establish hierarchy, not just decoration.</p></section>
<section class="ag-section"><h2>06 / Responsive Grid</h2><p>This pattern lets the browser decide how many columns fit based on the available width.</p><div class="ag-code"><code>.grid-container {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(220px, 1fr));
  gap: 20px;
}</code></div><div class="ag-grid"><div class="ag-card"><h3>auto-fit</h3><p>Fits as many columns as the available space allows.</p></div><div class="ag-card"><h3>minmax(220px, 1fr)</h3><p>Each column aims to be at least 220px wide and can grow to share the available space.</p></div><div class="ag-card"><h3>Responsive result</h3><p>Wide screens show more columns; narrow screens show fewer.</p></div></div><p>Another approach is to use media queries when you want precise control at particular breakpoints.</p></section>
<section class="ag-section"><h2>07 / Grid or Flexbox?</h2><div class="ag-table-wrap">MADTINKERBLOCKTOKEN0END</div><div class="ag-callout ag-green">You can use both in the same project: Grid for the overall gallery and Flexbox inside a card to align its title and button.</div></section>

<section class="ag-section"><h2>08 / Troubleshooting</h2><div class="ag-grid"><div class="ag-card"><h3>CSS does not appear</h3><p>Check that both files are in the same folder and that the stylesheet filename matches exactly.</p></div><div class="ag-card"><h3>Grid overflows</h3><p>Try <code class="ag-inline">minmax(0, 1fr)</code> for flexible columns and check for long unbreakable content.</p></div><div class="ag-card"><h3>Featured card looks odd on mobile</h3><p>Reset <code class="ag-inline">grid-column: auto</code> at the narrow-screen breakpoint.</p></div><div class="ag-card"><h3>Spacing looks inconsistent</h3><p>Use <code class="ag-inline">gap</code> on the grid container rather than adding different margins to every card.</p></div></div></section>
