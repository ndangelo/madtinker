## 02 / Control Your Color Stops

A color stop tells the browser where a particular color should appear in the gradient. Without percentages, CSS distributes the colors evenly. Adding percentages gives you more control over the composition.


<div class="gp-demo" style="background:linear-gradient(90deg,#14213d 0%,#00b4d8 38%,#c8ff3d 72%,#ff82c8 100%);"></div>


<div class="gp-code"><span class="gp-prop">background</span>: <span class="gp-fn">linear-gradient</span>(
  <span class="gp-value">90deg</span>,
  <span class="gp-color">#14213d</span> <span class="gp-value">0%</span>,
  <span class="gp-color">#00b4d8</span> <span class="gp-value">38%</span>,
  <span class="gp-color">#c8ff3d</span> <span class="gp-value">72%</span>,
  <span class="gp-color">#ff82c8</span> <span class="gp-value">100%</span>
);</div>


**Try it:** Change 38% to 20%, then change 72% to 85%. Watch how the bands of color expand and contract.

- **Earlier stop:** the color transition begins sooner.
- **Later stop:** the color occupies more of the gradient's path.
- **Repeated stop positions:** can create a sharp boundary instead of a smooth blend.

## 03 / Make Hard Edges

Gradients don't always have to be smooth. You can use repeated color-stop positions to create crisp stripes, graphic divisions, and poster-like compositions.


<div class="gp-demo" style="background:linear-gradient(90deg,#101b35 0% 25%,#75cfff 25% 50%,#ff9c55 50% 75%,#ff82c8 75% 100%);"></div>


<div class="gp-code"><span class="gp-prop">background</span>: <span class="gp-fn">linear-gradient</span>(
  <span class="gp-value">90deg</span>,
  <span class="gp-color">#101b35</span> 0% 25%,
  <span class="gp-color">#75cfff</span> 25% 50%,
  <span class="gp-color">#ff9c55</span> 50% 75%,
  <span class="gp-color">#ff82c8</span> 75% 100%
);</div>


This technique is useful for bold editorial layouts, geometric illustrations, and interface elements that need clearly separated colors.

## 04 / Layer Multiple Gradients

You can put more than one gradient in a single `background` declaration. Separate each gradient with a comma. The first layer is painted on top of the following layers.


<div class="gp-demo" style="background:radial-gradient(circle at 20% 25%,#ff82c8 0%,transparent 36%),radial-gradient(circle at 80% 70%,#75cfff 0%,transparent 40%),linear-gradient(135deg,#101b35,#263b60);"></div>


<div class="gp-code"><span class="gp-prop">background</span>:
  <span class="gp-fn">radial-gradient</span>(
    circle at 20% 25%,
    <span class="gp-color">#ff82c8</span> 0%,
    transparent 36%
  ),
  <span class="gp-fn">radial-gradient</span>(
    circle at 80% 70%,
    <span class="gp-color">#75cfff</span> 0%,
    transparent 40%
  ),
  <span class="gp-fn">linear-gradient</span>(
    135deg,
    <span class="gp-color">#101b35</span>,
    <span class="gp-color">#263b60</span>
  );</div>


**How it works:**

1. The first radial gradient creates a pink glow in the upper-left area.
2. The second creates a blue glow in the lower-right area.
3. The linear gradient provides the dark base behind both glows.


<div class="gp-note">
<strong>Experiment:</strong> Move the radial-gradient positions, change their colors, and adjust the percentages where each glow becomes transparent. Transparency allows the layers below to show through.
  </div>


## 05 / Explore Conic Gradients

A conic gradient changes color as it rotates around a center point. Think of a color wheel, a radar graphic, or a circular chart. Unlike a radial gradient, its colors travel around the center rather than outward from it.


<div class="gp-grid">
<div class="gp-card">
<h3>Color wheel</h3>
<div class="gp-demo" style="border-radius:50%;background:conic-gradient(#ff5252,#ffb347,#f9f871,#75e6a5,#75cfff,#a78bfa,#ff82c8,#ff5252);"></div>
<div class="gp-code"><span class="gp-prop">background</span>:
  <span class="gp-fn">conic-gradient</span>(
    <span class="gp-color">#ff5252</span>,
    <span class="gp-color">#ffb347</span>,
    <span class="gp-color">#f9f871</span>,
    <span class="gp-color">#75e6a5</span>,
    <span class="gp-color">#75cfff</span>,
    <span class="gp-color">#a78bfa</span>,
    <span class="gp-color">#ff82c8</span>,
    <span class="gp-color">#ff5252</span>
  );
  <span class="gp-prop">border-radius</span>: 50%;</div>
</div>
<div class="gp-card">
<h3>Graphic segments</h3>
<div class="gp-demo" style="border-radius:50%;background:conic-gradient(#c8ff3d 0deg 90deg,#75cfff 90deg 180deg,#ff82c8 180deg 270deg,#ff9c55 270deg 360deg);"></div>
<div class="gp-code"><span class="gp-prop">background</span>:
  <span class="gp-fn">conic-gradient</span>(
    <span class="gp-color">#c8ff3d</span> 0deg 90deg,
    <span class="gp-color">#75cfff</span> 90deg 180deg,
    <span class="gp-color">#ff82c8</span> 180deg 270deg,
    <span class="gp-color">#ff9c55</span> 270deg 360deg
  );
  <span class="gp-prop">border-radius</span>: 50%;</div>
</div>
</div>


**Try it:** Change the color stops or use `from 45deg` after `conic-gradient(` to rotate the starting point.

## 06 / Build Repeating Patterns

Repeating gradients produce stripes, rings, and textures. They're particularly useful when you want a pattern without importing an image.


<div class="gp-grid">
<div class="gp-card">
<h3>Diagonal stripes</h3>
<div class="gp-demo" style="background:repeating-linear-gradient(135deg,#101b35 0px,#101b35 10px,#75cfff 10px,#75cfff 20px);"></div>
<div class="gp-code"><span class="gp-prop">background</span>:
  <span class="gp-fn">repeating-linear-gradient</span>(
    135deg,
    <span class="gp-color">#101b35</span> 0px,
    <span class="gp-color">#101b35</span> 10px,
    <span class="gp-color">#75cfff</span> 10px,
    <span class="gp-color">#75cfff</span> 20px
  );</div>
</div>
<div class="gp-card">
<h3>Concentric rings</h3>
<div class="gp-demo" style="background:repeating-radial-gradient(circle,#ff82c8 0px,#ff82c8 8px,#101b35 8px,#101b35 16px);"></div>
<div class="gp-code"><span class="gp-prop">background</span>:
  <span class="gp-fn">repeating-radial-gradient</span>(
    circle,
    <span class="gp-color">#ff82c8</span> 0px,
    <span class="gp-color">#ff82c8</span> 8px,
    <span class="gp-color">#101b35</span> 8px,
    <span class="gp-color">#101b35</span> 16px
  );</div>
</div>
</div>


The key is the distance between the color stops. Smaller intervals create finer patterns; larger intervals create broader stripes and rings.

## 07 / Animate a Gradient

CSS gradients can also create motion. One practical technique is to make a background larger than its container and animate its position.


<div class="gp-demo gp-animated" style="min-height:155px;"></div>


<div class="gp-code"><span class="gp-prop">.animated-gradient</span> {
  <span class="gp-prop">background</span>: <span class="gp-fn">linear-gradient</span>(
    120deg,
    <span class="gp-color">#101b35</span>,
    <span class="gp-color">#176b87</span>,
    <span class="gp-color">#8b5cf6</span>,
    <span class="gp-color">#ff82c8</span>,
    <span class="gp-color">#ff9c55</span>
  );
  <span class="gp-prop">background-size</span>: 300% 300%;
  <span class="gp-prop">animation</span>: gradient-shift 8s ease infinite;
}

@keyframes gradient-shift {
  0%   { background-position: 0% 50%; }
  50%  { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}</div>


**Important:** The animation works because the background is larger than the visible element. The keyframes move that oversized background back and forth.


<div class="gp-note">
<strong>Accessibility tip:</strong> Avoid rapid, flashing, or distracting motion. Keep important text readable against the background and respect users who prefer reduced motion. The lesson's animated demonstration stops when the browser requests reduced motion.
  </div>
