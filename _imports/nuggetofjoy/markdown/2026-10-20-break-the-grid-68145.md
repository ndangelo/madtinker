Use CSS Grid to create an asymmetrical composition with oversized features, unexpected proportions, bold color, and a responsive layout that changes as the screen gets smaller.</p><div class="ag-chips"><span class="ag-chip">CSS Grid Remix</span><span class="ag-chip">Art direction</span><span class="ag-chip">Responsive design</span><span class="ag-chip">Creative lab</span></div></header>

<section class="ag-section"><h2>01 / The creative challenge</h2><p>In Part I, you built a project gallery using a regular grid. For Part II, imagine that your portfolio is not a collection of equal cards—it is a small digital exhibition with a point of view.</p><p>Your task is to design a one-page experience for a fictional creative practice, art exhibition, music label, fashion concept, experimental magazine, or design studio. The layout should feel intentional, surprising, and connected to the subject.</p>
<div class="ag-grid">
<div class="ag-card"><div class="ag-number">A</div><h3>Choose a concept</h3><p>Invent a creative identity or exhibition. Give it a name, a mood, and a visual direction.</p></div>
<div class="ag-card"><div class="ag-number">B</div><h3>Break the pattern</h3><p>Use different card sizes, a feature that spans columns, and at least one deliberate asymmetry.</p></div>
<div class="ag-card"><div class="ag-number">C</div><h3>Make it adapt</h3><p>Rework the layout for smaller screens. The mobile version should feel designed—not simply squeezed.</p></div>
</div>
<div class="ag-callout"><strong>The rule:</strong> You must use CSS Grid as the main layout system. You can use color, type, shapes, images, gradients, and hover states—but every visual choice should support your concept.</div>
</section>
<section class="ag-section"><h2>02 / Find your visual direction</h2><p>Before coding, choose one creative direction. Use these as starting points, or invent your own.</p>
<div class="ag-grid">
<div class="ag-card"><div style="height:76px;border-radius:8px;background:linear-gradient(120deg,#f3d6bd 0 35%,#c63d2f 35% 62%,#202b47 62%);margin-bottom:14px"></div><h3>01 / Brutalist culture</h3><p>Oversized typography, hard edges, stark contrast, and unexpected alignment.</p><p class="ag-muted">Palette idea: cream, red, deep navy.</p></div>
<div class="ag-card"><div style="height:76px;border-radius:8px;background:radial-gradient(circle at 25% 50%,#f8d65c 0 15%,transparent 16%),linear-gradient(135deg,#161616,#3c326c,#db6e91);margin-bottom:14px"></div><h3>02 / Dream archive</h3><p>Soft gradients, layered imagery, atmospheric color, and unusual proportions.</p><p class="ag-muted">Palette idea: violet, pink, gold, black.</p></div>
<div class="ag-card"><div style="height:76px;border-radius:8px;background:repeating-linear-gradient(135deg,#f2f0e8 0 9px,#252525 9px 11px);margin-bottom:14px"></div><h3>03 / Editorial system</h3><p>Strict typography, modular information, graphic lines, and a controlled grid.</p><p class="ag-muted">Palette idea: black, paper, one accent.</p></div>
<div class="ag-card"><div style="height:76px;border-radius:8px;background:linear-gradient(115deg,#b8f34b 0 25%,#172235 25% 65%,#8bd5ff 65%);margin-bottom:14px"></div><h3>04 / Future lab</h3><p>Technical labels, vivid accents, geometric shapes, and a digital-instrument feel.</p><p class="ag-muted">Palette idea: acid green, blue, charcoal.</p></div>
</div>
</section>
<section class="ag-section"><h2>03 / Understand the composition</h2><p>Grid can do more than make equal columns. You can make a feature span multiple tracks, let an item occupy more than one row, and use empty space to create rhythm.</p>
<div class="ag-demo-grid"><span class="ag-wide ag-dark">HERO / FEATURE</span><span class="ag-lime">01</span><span class="ag-tall">02<br/>VERTICAL</span><span>03</span><span>04</span><span class="ag-wide">05 / WIDE</span><span class="ag-dark">INFO</span></div>
<p class="ag-muted">This is a schematic layout, not a finished design. Your final composition should reflect your own concept and content.</p>
<div class="ag-code"><code>.exhibition-grid {
  display: grid;
  grid-template-columns: repeat(4, minmax(0, 1fr));
  gap: 14px;
}

.feature {
  grid-column: span 2;
}

.vertical-feature {
  grid-row: span 2;
}</code></div>
<div class="ag-callout ag-green"><strong>Think like a designer:</strong> A large feature attracts attention. Smaller items create rhythm. Repeated gaps create consistency. Empty space gives the eye a place to rest.</div>
</section>

<section class="ag-section"><h2>05 / Your creative brief</h2>
<div class="ag-card"><h3>Design a one-page digital exhibition</h3><p>Invent a creative identity and build a responsive page that communicates its character through layout, typography, color, and rhythm.</p>
<ul class="ag-checklist">
<li>Choose a concept and give it a distinctive name.</li>
<li>Include a strong headline and a short introduction.</li>
<li>Create at least five content tiles or project panels.</li>
<li>Make one tile visually dominant by spanning columns or rows.</li>
<li>Use at least three coordinated colors and a clear typographic hierarchy.</li>
<li>Customize the sample content and styling; do not submit the starter unchanged.</li>
<li>Add one thoughtful hover interaction or transition.</li>
<li>Use media queries so the layout works on tablet and mobile screens.</li>
<li>Keep text readable and provide meaningful content, not just decorative boxes.</li>
</ul></div>
<h3>Push it further / Choose one wild card</h3>
<div class="ag-grid">
<div class="ag-card"><h3>Wild card A: The oversized object</h3><p>Create a tile that dominates the composition and deliberately breaks the visual rhythm.</p></div>
<div class="ag-card"><h3>Wild card B: The archive</h3><p>Include small labels, dates, edition numbers, or metadata to make the page feel like a curated archive.</p></div>
<div class="ag-card"><h3>Wild card C: The unexpected grid</h3><p>Use a different grid structure at mobile size instead of simply reducing the number of columns.</p></div>
<div class="ag-card"><h3>Wild card D: The visual interruption</h3><p>Introduce a contrasting tile, rotation, border treatment, or accent color that intentionally interrupts the pattern.</p></div>
</div>
</section>
<section class="ag-section"><h2>06 / Suggested workflow</h2>
<ol class="ag-steps">
<li><strong>Sketch first.</strong> Draw a rough desktop grid on paper. Decide which tile should attract attention first.</li>
<li><strong>Build the structure.</strong> Get the HTML and grid working before adding decorative details.</li>
<li><strong>Establish the visual system.</strong> Choose a palette, type scale, borders, and spacing rules.</li>
<li><strong>Make the composition expressive.</strong> Use spanning, scale, contrast, and negative space with purpose.</li>
<li><strong>Design the small-screen version.</strong> Decide what should stack, span, or change order.</li>
<li><strong>Test and refine.</strong> Save your files, refresh the browser, resize the window, and correct any overflow.</li>
</ol>
</section>
<section class="ag-section"><h2>07 / Submission checklist</h2>
<p>Before submitting, work through this list from top to bottom. Check each item only after you have verified it in your files or browser.</p>
<ul class="ag-checklist">
<li><code class="ag-inline">index.html</code> and <code class="ag-inline">style.css</code> are separate and saved in the same folder.</li>
<li>The page has a distinctive concept and a clear visual direction.</li>
<li>CSS Grid is used for the main composition.</li>
<li>At least one item spans multiple columns or rows.</li>
<li>The page uses intentional typography, color, and spacing.</li>
<li>A hover transition or other small interaction is included.</li>
<li>The layout adapts to tablet and mobile screens.</li>
<li>The page has been tested in a browser at more than one width.</li>
<li>A screenshot of the desktop layout and a screenshot of the mobile layout are ready.</li>
<li>A short reflection explains one design decision and one technical challenge.</li>
</ul>
<div class="ag-callout ag-green"><strong>Reflection prompts:</strong> What is the first thing viewers notice? How does the grid support your concept? What changed when you redesigned the layout for mobile? Which CSS Grid rule had the biggest impact?</div>
</section>
<section class="ag-section"><h2>08 / Troubleshooting</h2><div class="ag-grid">
<div class="ag-card"><h3>The layout overflows</h3><p>Use <code class="ag-inline">minmax(0, 1fr)</code> in your column definitions and check for long words or fixed-width elements.</p></div>
<div class="ag-card"><h3>The feature tile breaks on mobile</h3><p>Reset <code class="ag-inline">grid-column</code> and <code class="ag-inline">grid-row</code> in your narrow-screen media query.</p></div>
<div class="ag-card"><h3>The design feels random</h3><p>Repeat a few visual rules—such as spacing, borders, or type styles—so the unusual elements still feel connected.</p></div>
<div class="ag-card"><h3>The page looks flat</h3><p>Use stronger scale contrast, a more deliberate feature tile, and clearer differences between primary and secondary information.</p></div>
