<p class="ag-eyebrow">AMDE 355 · Advanced Web Design · Week 03</p>
<h2>Design for Every Screen.</h2>
<p>Responsive design is not a smaller desktop page. It is a system of layout decisions that adapt to the content, the device, and the way someone is using the page. This week, you’ll build a layout that changes composition—not just scale.</p>
<div class="ag-chips"><span class="ag-chip">Responsive systems</span><span class="ag-chip">Fluid sizing</span><span class="ag-chip">Media queries</span><span class="ag-chip">Mobile-first thinking</span></div>
</section>
<section class="ag-section">
<h2>01 / The challenge — design the change</h2>
<p>A responsive layout should preserve the message while adapting its arrangement. A three-column gallery might become two columns, then one. Navigation might wrap or change alignment. Type should remain readable without awkward jumps.</p>
<div class="ag-grid">
<article class="ag-card"><span class="ag-number">01</span><h3>Fluid foundations</h3><p>Use relative units, flexible containers, and intrinsic sizing so the layout can grow and shrink.</p></article>
<article class="ag-card"><span class="ag-number">02</span><h3>Intentional breakpoints</h3><p>Add a media query when the content needs a different arrangement—not because a device list says so.</p></article>
<article class="ag-card"><span class="ag-number">03</span><h3>Content priority</h3><p>Decide what must stay prominent and what can move, stack, or become more compact.</p></article>
</div>
<div class="ag-callout"><strong>Design question:</strong> At what point does your layout stop working well? Use that moment—not a device label—to choose a breakpoint.</div>
</section>
<section class="ag-section">
<h2>02 / Fluid sizing before breakpoints</h2>
<p>Start by making the page flexible. <code class="ag-inline">max-width</code> prevents long lines from becoming uncomfortable; percentages allow a container to adapt; <code class="ag-inline">clamp()</code> sets a minimum, preferred, and maximum size.</p>
<div class="ag-editor">
<div class="ag-editor-head"><span class="ag-dot"></span><span class="ag-dot"></span><span class="ag-dot"></span><span class="ag-editor-title">fluid-foundation.css</span></div>
<div class="ag-code"><span class="tok-selector">.page</span> <span class="tok-punct">{</span>
<span class="tok-prop">width</span><span class="tok-punct">:</span> <span class="tok-value">min(92%, 1200px)</span><span class="tok-punct">;</span>
<span class="tok-prop">margin-inline</span><span class="tok-punct">:</span> <span class="tok-value">auto</span><span class="tok-punct">;</span>
<span class="tok-punct">}</span>
<span class="tok-selector">.page-title</span> <span class="tok-punct">{</span>
<span class="tok-prop">font-size</span><span class="tok-punct">:</span> <span class="tok-value">clamp(2.5rem, 7vw, 6.5rem)</span><span class="tok-punct">;</span>
<span class="tok-prop">line-height</span><span class="tok-punct">:</span> <span class="tok-num">.95</span><span class="tok-punct">;</span>
<span class="tok-punct">}</span>
<span class="tok-selector">img</span> <span class="tok-punct">{</span>
<span class="tok-prop">max-width</span><span class="tok-punct">:</span> <span class="tok-num">100%</span><span class="tok-punct">;</span>
<span class="tok-prop">height</span><span class="tok-punct">:</span> <span class="tok-value">auto</span><span class="tok-punct">;</span>
<span class="tok-prop">display</span><span class="tok-punct">:</span> <span class="tok-value">block</span><span class="tok-punct">;</span>
<span class="tok-punct">}</span></div>
</div>
<div class="ag-callout blue"><strong>Try it:</strong> Change the preferred value in <code class="ag-inline">clamp()</code> from <code class="ag-inline">7vw</code> to <code class="ag-inline">5vw</code>. Resize the browser and watch how the title responds.</div>
</section>
<section class="ag-section">
<h2>03 / Build a responsive grid</h2>
<p>Use Grid’s intrinsic sizing to fit as many columns as comfortably fit in the available space. This can reduce the number of breakpoints you need.</p>
<div class="ag-editor">
<div class="ag-editor-head"><span class="ag-dot"></span><span class="ag-dot"></span><span class="ag-dot"></span><span class="ag-editor-title">responsive-grid.css</span></div>
<div class="ag-code"><span class="tok-selector">.project-grid</span> <span class="tok-punct">{</span>
<span class="tok-prop">display</span><span class="tok-punct">:</span> <span class="tok-value">grid</span><span class="tok-punct">;</span>
<span class="tok-prop">grid-template-columns</span><span class="tok-punct">:</span>
<span class="tok-value">repeat</span><span class="tok-punct">(</span><span class="tok-value">auto-fit</span><span class="tok-punct">,</span> <span class="tok-value">minmax</span><span class="tok-punct">(</span><span class="tok-num">240px</span><span class="tok-punct">,</span> <span class="tok-num">1fr</span><span class="tok-punct">));</span>
<span class="tok-prop">gap</span><span class="tok-punct">:</span> <span class="tok-num">1rem</span><span class="tok-punct">;</span>
<span class="tok-punct">}</span>
<span class="tok-selector">.project-card</span> <span class="tok-punct">{</span>
<span class="tok-prop">min-width</span><span class="tok-punct">:</span> <span class="tok-num">0</span><span class="tok-punct">;</span>
<span class="tok-prop">padding</span><span class="tok-punct">:</span> <span class="tok-num">1.25rem</span><span class="tok-punct">;</span>
<span class="tok-prop">border</span><span class="tok-punct">:</span> <span class="tok-num">1px</span> <span class="tok-value">solid #182033</span><span class="tok-punct">;</span>
<span class="tok-punct">}</span></div>
</div>
<p><strong>Discuss:</strong> <code class="ag-inline">auto-fit</code> lets the browser fit as many columns as possible. <code class="ag-inline">minmax(240px, 1fr)</code> sets a minimum card width while allowing remaining space to be shared.</p>
</section>
<section class="ag-section">
<h2>04 / Add breakpoints when the design needs them</h2>
<p>Some changes are art-direction decisions. Maybe the featured story should move above the gallery, the navigation should stack, or the page padding should tighten.</p>
<div class="ag-editor">
<div class="ag-editor-head"><span class="ag-dot"></span><span class="ag-dot"></span><span class="ag-dot"></span><span class="ag-editor-title">responsive-breakpoints.css</span></div>
<div class="ag-code"><span class="tok-comment">/* Tablet / compact layout */</span>
<span class="tok-key">@media</span> <span class="tok-punct">(</span><span class="tok-prop">max-width</span><span class="tok-punct">:</span> <span class="tok-num">800px</span><span class="tok-punct">)</span> <span class="tok-punct">{</span>
<span class="tok-selector">.page-layout</span> <span class="tok-punct">{</span>
<span class="tok-prop">grid-template-columns</span><span class="tok-punct">:</span> <span class="tok-num">1fr</span><span class="tok-punct">;</span>
<span class="tok-punct">}</span>
<span class="tok-selector">.site-nav</span> <span class="tok-punct">{</span>
<span class="tok-prop">flex-wrap</span><span class="tok-punct">:</span> <span class="tok-value">wrap</span><span class="tok-punct">;</span>
<span class="tok-punct">}</span>
<span class="tok-punct">}</span>
<span class="tok-comment">/* Small-screen refinements */</span>
<span class="tok-key">@media</span> <span class="tok-punct">(</span><span class="tok-prop">max-width</span><span class="tok-punct">:</span> <span class="tok-num">520px</span><span class="tok-punct">)</span> <span class="tok-punct">{</span>
<span class="tok-selector">.page</span> <span class="tok-punct">{</span>
<span class="tok-prop">width</span><span class="tok-punct">:</span> <span class="tok-num">94%</span><span class="tok-punct">;</span>
<span class="tok-punct">}</span>
<span class="tok-selector">.section</span> <span class="tok-punct">{</span>
<span class="tok-prop">padding-block</span><span class="tok-punct">:</span> <span class="tok-num">2rem</span><span class="tok-punct">;</span>
<span class="tok-punct">}</span>
<span class="tok-punct">}</span></div>
</div>
<div class="ag-callout blue"><strong>Breakpoint rule:</strong> Resize the preview slowly. When the composition starts to feel cramped or the reading order becomes unclear, pause and add a breakpoint there.</div>
</section>
<section class="ag-section">
<h2>05 / Responsive design is more than width</h2>
<div class="ag-grid">
<article class="ag-card"><h3>Typography</h3><p>Use comfortable line lengths, fluid type where appropriate, and enough line-height for readability.</p></article>
<article class="ag-card"><h3>Images and media</h3><p>Prevent images from overflowing their containers. Preserve useful crops and make sure visual content remains understandable.</p></article>
<article class="ag-card"><h3>Interaction</h3><p>Ensure links and controls remain easy to identify and use at narrow widths and with touch input.</p></article>
<article class="ag-card"><h3>Content order</h3><p>Make sure the visual arrangement does not undermine the logical reading order in the HTML.</p></article>
</div>
</section>
<section class="ag-section">
<h2>06 / Instructor demo — the responsive remix</h2>
<p>Build one page and test it at three widths. Ask students to predict the change before each edit.</p>
<ol class="ag-steps">
<li><strong>Desktop:</strong> Start with a feature area beside a three-column project grid. Identify the visual focal point.</li>
<li><strong>Fluid pass:</strong> Add a max-width container, fluid title sizing, and responsive images before adding breakpoints.</li>
<li><strong>Tablet pass:</strong> Resize until the grid cards feel cramped. Change the layout to two columns or one column based on the content.</li>
<li><strong>Mobile pass:</strong> Reduce side padding, stack the navigation if needed, and check for overflow.</li>
<li><strong>Compare:</strong> Ask which content changed position and whether the hierarchy stayed clear.</li>
</ol>
</section>
<section class="ag-section">
<h2>07 / Studio assignment — one page, three contexts</h2>
<p>Create or adapt a portfolio, exhibition, event, or project page. Design the desktop layout first, then make deliberate changes for tablet and mobile.</p>
<div class="ag-grid">
<article class="ag-card"><span class="ag-number">A</span><h3>Desktop</h3><p>Use a clear hierarchy and an intentional grid or split layout.</p></article>
<article class="ag-card"><span class="ag-number">B</span><h3>Tablet</h3><p>Adjust columns, spacing, or navigation where the content needs it.</p></article>
<article class="ag-card"><span class="ag-number">C</span><h3>Mobile</h3><p>Prioritize reading order, legibility, tap targets, and a clean single-column flow when appropriate.</p></article>
</div>
<div class="ag-callout"><strong>Constraint:</strong> Use at least one fluid sizing technique and at least one media query. Avoid building the whole page with fixed pixel widths.</div>
</section>
<section class="ag-section">
<h2>08 / What to submit</h2>
<ul class="ag-checklist">
<li>Working CodePen link or project files.</li>
<li>Desktop, tablet, and mobile screenshots.</li>
<li>At least one example of fluid sizing, such as percentages, <code class="ag-inline">min()</code>, <code class="ag-inline">max()</code>, or <code class="ag-inline">clamp()</code>.</li>
<li>At least one media query with a clear purpose.</li>
<li>A short note explaining where you placed your breakpoint and why.</li>
</ul>
</section>

<h3>Step 5 — Test and narrate the design</h3>
<ol class="ag-steps">
<li>Start wide and identify the page's focal point.</li>
<li>Resize the preview slowly and note when the layout shifts naturally.</li>
<li>Cross the breakpoint and explain which rule changes the composition.</li>
<li>Check for horizontal overflow, cramped text, and uneven spacing.</li>
<li>Ask: “What did we allow the browser to handle, and what did we decide as designers?”</li>
</ol>
<div class="ag-callout blue"><strong>Instructor note:</strong> This demonstration deliberately shows both intrinsic responsiveness (the grid adapts without a media query) and art direction (the breakpoint changes a specific design choice). Keep those concepts separate during the explanation.</div>

<section class="ag-section">
<h2>09 / Final quality check</h2>
<ul class="ag-checklist">
<li>The layout adapts to wide, medium, and narrow viewports.</li>
<li>Fluid sizing is used for the container or typography.</li>
<li>At least one breakpoint has a clear content-driven purpose.</li>
<li>Images and cards do not overflow their containers.</li>
<li>The reading order and visual hierarchy remain clear.</li>
</ul>
