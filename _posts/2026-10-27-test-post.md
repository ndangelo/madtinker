  <h2>01 / Start Here</h2>
  <p>In Part 1, you explored linear and radial gradients. Now we&#8217;ll use those same tools in more creative ways. You&#8217;ll learn how to control exactly where colors change, combine multiple gradients, make repeating patterns, and animate a gradient background.</p>

  <div class="gp-grid">
    <div class="gp-card">
      <h3>What you&#8217;ll learn</h3>
      <ul>
        <li>Control color stops and hard edges.</li>
        <li>Layer multiple background images.</li>
        <li>Create conic and repeating gradients.</li>
        <li>Animate a gradient effect.</li>
      </ul>
    </div>
    <div class="gp-card">
      <h3>What you&#8217;ll need</h3>
      <ul>
        <li>A browser and your CodePen account.</li>
        <li>Your HTML and CSS skills from previous lessons.</li>
        <li>A small color palette of your choice.</li>
      </ul>
    </div>
  </div>

  <div class="gp-note">
    <strong>Remember:</strong> A gradient is generated by the browser. You don&#8217;t need to download an image or create a Photoshop file. Gradients can be used anywhere CSS accepts an image, including an element&#8217;s background.
  </div>

  <h2>02 / Control Your Color Stops</h2>
  <p>A color stop tells the browser where a particular color should appear in the gradient. Without percentages, CSS distributes the colors evenly. Adding percentages gives you more control over the composition.</p>

  <div class="gp-demo" style="background:linear-gradient(90deg,#14213d 0%,#00b4d8 38%,#c8ff3d 72%,#ff82c8 100%);"></div>

  <div class="gp-code"><span class="gp-prop">background</span>: <span class="gp-fn">linear-gradient</span>(
  <span class="gp-value">90deg</span>,
  <span class="gp-color">#14213d</span> <span class="gp-value">0%</span>,
  <span class="gp-color">#00b4d8</span> <span class="gp-value">38%</span>,
  <span class="gp-color">#c8ff3d</span> <span class="gp-value">72%</span>,
  <span class="gp-color">#ff82c8</span> <span class="gp-value">100%</span>
);</div>

  <p><strong>Try it:</strong> Change 38% to 20%, then change 72% to 85%. Watch how the bands of color expand and contract.</p>
  <ul>
    <li><strong>Earlier stop:</strong> the color transition begins sooner.</li>
    <li><strong>Later stop:</strong> the color occupies more of the gradient&#8217;s path.</li>
    <li><strong>Repeated stop positions:</strong> can create a sharp boundary instead of a smooth blend.</li>
  </ul>

  <h2>03 / Make Hard Edges</h2>
  <p>Gradients don&#8217;t always have to be smooth. You can use repeated color-stop positions to create crisp stripes, graphic divisions, and poster-like compositions.</p>

  <div class="gp-demo" style="background:linear-gradient(90deg,#101b35 0% 25%,#75cfff 25% 50%,#ff9c55 50% 75%,#ff82c8 75% 100%);"></div>

  <div class="gp-code"><span class="gp-prop">background</span>: <span class="gp-fn">linear-gradient</span>(
  <span class="gp-value">90deg</span>,
  <span class="gp-color">#101b35</span> 0% 25%,
  <span class="gp-color">#75cfff</span> 25% 50%,
  <span class="gp-color">#ff9c55</span> 50% 75%,
  <span class="gp-color">#ff82c8</span> 75% 100%
);</div>

  <p>This technique is useful for bold editorial layouts, geometric illustrations, and interface elements that need clearly separated colors.</p>

  <h2>04 / Layer Multiple Gradients</h2>
  <p>You can put more than one gradient in a single <code>background</code> declaration. Separate each gradient with a comma. The first layer is painted on top of the following layers.</p>

  <div class="gp-demo" style="background:radial-gradient(circle at 20% 25%,#ff82c8 0%,transparent 36%),radial-gradient(circle at 80% 70%,#75cfff 0%,transparent 40%),linear-gradient(135deg,#101b35,#263b60);"></div>

  <div class="gp-code"><span class="gp-prop">background</span>:
  <span class="gp-fn">radial-gradient</span>(
    circle at 20% 25%,
    <span class="gp-color">#ff82c8</span> 0%,
    transparent 36%
  ),
  <span class="gp-fn">radial-gradient</span>(
    circle at 80% 70%,
    <span class="gp-color">#75cfff</span> 0%,
    transparent 40%
  ),
  <span class="gp-fn">linear-gradient</span>(
    135deg,
    <span class="gp-color">#101b35</span>,
    <span class="gp-color">#263b60</span>
  );</div>

  <p><strong>How it works:</strong></p>
  <ol>
    <li>The first radial gradient creates a pink glow in the upper-left area.</li>
    <li>The second creates a blue glow in the lower-right area.</li>
    <li>The linear gradient provides the dark base behind both glows.</li>
  </ol>

  <div class="gp-note">
    <strong>Experiment:</strong> Move the radial-gradient positions, change their colors, and adjust the percentages where each glow becomes transparent. Transparency allows the layers below to show through.
  </div>

  <h2>05 / Explore Conic Gradients</h2>
  <p>A conic gradient changes color as it rotates around a center point. Think of a color wheel, a radar graphic, or a circular chart. Unlike a radial gradient, its colors travel around the center rather than outward from it.</p>

  <div class="gp-grid">
    <div class="gp-card">
      <h3>Color wheel</h3>
      <div class="gp-demo" style="border-radius:50%;background:conic-gradient(#ff5252,#ffb347,#f9f871,#75e6a5,#75cfff,#a78bfa,#ff82c8,#ff5252);"></div>
      <div class="gp-code"><span class="gp-prop">background</span>:
  <span class="gp-fn">conic-gradient</span>(
    <span class="gp-color">#ff5252</span>,
    <span class="gp-color">#ffb347</span>,
    <span class="gp-color">#f9f871</span>,
    <span class="gp-color">#75e6a5</span>,
    <span class="gp-color">#75cfff</span>,
    <span class="gp-color">#a78bfa</span>,
    <span class="gp-color">#ff82c8</span>,
    <span class="gp-color">#ff5252</span>
  );
  <span class="gp-prop">border-radius</span>: 50%;</div>
    </div>
    <div class="gp-card">
      <h3>Graphic segments</h3>
      <div class="gp-demo" style="border-radius:50%;background:conic-gradient(#c8ff3d 0deg 90deg,#75cfff 90deg 180deg,#ff82c8 180deg 270deg,#ff9c55 270deg 360deg);"></div>
      <div class="gp-code"><span class="gp-prop">background</span>:
  <span class="gp-fn">conic-gradient</span>(
    <span class="gp-color">#c8ff3d</span> 0deg 90deg,
    <span class="gp-color">#75cfff</span> 90deg 180deg,
    <span class="gp-color">#ff82c8</span> 180deg 270deg,
    <span class="gp-color">#ff9c55</span> 270deg 360deg
  );
  <span class="gp-prop">border-radius</span>: 50%;</div>
    </div>
  </div>

  <p><strong>Try it:</strong> Change the color stops or use <code>from 45deg</code> after <code>conic-gradient(</code> to rotate the starting point.</p>

  <h2>06 / Build Repeating Patterns</h2>
  <p>Repeating gradients produce stripes, rings, and textures. They&#8217;re particularly useful when you want a pattern without importing an image.</p>

  <div class="gp-grid">
    <div class="gp-card">
      <h3>Diagonal stripes</h3>
      <div class="gp-demo" style="background:repeating-linear-gradient(135deg,#101b35 0px,#101b35 10px,#75cfff 10px,#75cfff 20px);"></div>
      <div class="gp-code"><span class="gp-prop">background</span>:
  <span class="gp-fn">repeating-linear-gradient</span>(
    135deg,
    <span class="gp-color">#101b35</span> 0px,
    <span class="gp-color">#101b35</span> 10px,
    <span class="gp-color">#75cfff</span> 10px,
    <span class="gp-color">#75cfff</span> 20px
  );</div>
    </div>
    <div class="gp-card">
      <h3>Concentric rings</h3>
      <div class="gp-demo" style="background:repeating-radial-gradient(circle,#ff82c8 0px,#ff82c8 8px,#101b35 8px,#101b35 16px);"></div>
      <div class="gp-code"><span class="gp-prop">background</span>:
  <span class="gp-fn">repeating-radial-gradient</span>(
    circle,
    <span class="gp-color">#ff82c8</span> 0px,
    <span class="gp-color">#ff82c8</span> 8px,
    <span class="gp-color">#101b35</span> 8px,
    <span class="gp-color">#101b35</span> 16px
  );</div>
    </div>
  </div>

  <p>The key is the distance between the color stops. Smaller intervals create finer patterns; larger intervals create broader stripes and rings.</p>

  <h2>07 / Animate a Gradient</h2>
  <p>CSS gradients can also create motion. One practical technique is to make a background larger than its container and animate its position.</p>

  <style>
    @keyframes gp-gradient-shift {
      0% { background-position: 0% 50%; }
      50% { background-position: 100% 50%; }
      100% { background-position: 0% 50%; }
    }
    .gradient-part-two .gp-animated {
      background: linear-gradient(120deg,#101b35,#176b87,#8b5cf6,#ff82c8,#ff9c55,#101b35);
      background-size: 300% 300%;
      animation: gp-gradient-shift 8s ease infinite;
    }
  </style>

  <div class="gp-demo gp-animated" style="min-height:155px;"></div>

  <div class="gp-code"><span class="gp-prop">.animated-gradient</span> {
  <span class="gp-prop">background</span>: <span class="gp-fn">linear-gradient</span>(
    120deg,
    <span class="gp-color">#101b35</span>,
    <span class="gp-color">#176b87</span>,
    <span class="gp-color">#8b5cf6</span>,
    <span class="gp-color">#ff82c8</span>,
    <span class="gp-color">#ff9c55</span>
  );
  <span class="gp-prop">background-size</span>: 300% 300%;
  <span class="gp-prop">animation</span>: gradient-shift 8s ease infinite;
}

@keyframes gradient-shift {
  0%   { background-position: 0% 50%; }
  50%  { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}</div>

  <p><strong>Important:</strong> The animation works because the background is larger than the visible element. The keyframes move that oversized background back and forth.</p>

  <div class="gp-note">
    <strong>Accessibility tip:</strong> Avoid rapid, flashing, or distracting motion. Keep important text readable against the background and respect users who prefer reduced motion. The lesson&#8217;s animated demonstration stops when the browser requests reduced motion.
  </div>
